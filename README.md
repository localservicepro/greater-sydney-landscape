# Greater Sydney Landscapes — website

Static, dependency-free rebuild of [greatersydneylandscapes.com.au](https://greatersydneylandscapes.com.au/), built against the Step 1 SEO research report (primary target: *lawn mowing sydney*).

## Structure

| Path | What it is |
|---|---|
| `src/data/site.js` | Business details, services, service areas, FAQ copy. Titles / H1s / meta descriptions come from the approved SEO report. |
| `src/data/generated.js` | Provenance for AI-generated fill-in imagery (currently only the pressure-washing photo). |
| `src/lib/layout.js` | Document shell, header (mega-dropdown + mobile menu + call bar), footer, schema builders, responsive `<img>` helper. |
| `src/pages/*.js` | Page templates: home, services index, service pages, about, areas, contact, thank-you, 404. |
| `src/assets/css/main.css` | Design system (charcoal + three greens sampled from the logo, Montserrat / Inter, swoosh motif, motion). |
| `src/assets/js/main.js` | Nav, reveal / parallax / marquee, FAQ accordion, custom cursor, quote-form handling. |
| `src/assets/img/` | Optimised WebP variants (generated by `scripts/images.py` from `src/assets/img/raw/`, which is git-ignored). |
| `scripts/images.py` | Image pipeline: responsive WebP sizes, LQIP, favicons, OG image, `manifest.json`. |
| `scripts/seo-check.mjs` | Post-build checks: one H1, title / description length, alt text, JSON-LD validity, broken links, tracking script present. |
| `redirects.txt` | Redirect map (mirrored into `dist/_redirects` and `vercel.json`). |
| `dist/` | Built site. Deploy this folder to any static host. |

## Build

```bash
node build.mjs          # renders dist/
node scripts/seo-check.mjs
python3 scripts/images.py   # only needed when raw photos change (needs Pillow)
```

Preview locally with `python3 -m http.server 4173 --directory dist`.

## Hosting

Works on Netlify (`netlify.toml`), Vercel (`vercel.json`) or any static host that serves `index.html` for directory URLs. Point the apex domain at the host and keep `www` redirecting to the apex (both configs include that rule).

## Forms / CRM

The quote form posts nothing itself. The GoHighLevel external-tracking script (`tk_5987fdfaee534a7aa664816fa84b7e3b`) is loaded in `<head>` on every page and captures submissions from the DOM; the page then redirects to `/thank-you/`. Field names map to the CRM contact fields:

`full_name`, `email`, `phone`, `property_address`, `property_size`, `service_needed`, `job_notes`.

## Images

All photography is the client's own work from the shared Google Drive folder, except `pressure-washing-*.webp`, which was AI-generated (Higgsfield) because no pressure-washing job photo was supplied. Replace it by dropping a real photo in `src/assets/img/raw/`, adding it to `IMAGES` in `scripts/images.py` as `pressure-washing`, and re-running the pipeline.
